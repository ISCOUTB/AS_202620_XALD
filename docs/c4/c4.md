# C4 Model

## Overview

El modelo C4 documenta la arquitectura en niveles de abstracción. Cada nivel tiene un único archivo vigente:

- **C1 - Context**: [c1.md](c1.md). Usuarios y sistemas externos.
- **C2 - Container**: [c2.md](c2.md). Contenedores técnicos, almacenes y flujo de datos.
- **C3 - Component**: [c3.md](c3.md). Componentes de la aplicación móvil Android.
- **C4 - Code**: no se documenta; el código vive en `XALDAPP/` y `backend/`.

**Estado del código revisado:** rama `master`, revisión del 22 de noviembre de 2026.

## Purpose

Ofrece una forma clara y escalable de comunicar la arquitectura a distintos interesados con distintos niveles de detalle.
